5.1 Types of Error

Irreducible Error

The noise in the data that cannot be removed, no matter how good your model is. All models will always have some irreducible error.

Reducible Error

The part of error that can be reduced by choosing better models, features, or techniques. Has two components: Bias + Variance.

Bias

The difference between actual and predicted values. High bias = model is too simple to capture the complexity of data → Underfitting.

Variance

The model's sensitivity to small fluctuations when trained on small subsets of the same training data. High variance = model is too complex, captures noise as patterns → Overfitting.

5.4 How to Handle It?

  • Cross-Validation — detect and measure bias/variance accurately
  • Feature Engineering — better features reduce both bias and variance
  • Ensemble Methods — combine multiple models to balance bias and variance
  • Regularization — penalize complexity to control variance
  • More data — reduces variance in complex models
