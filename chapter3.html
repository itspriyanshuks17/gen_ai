Introduction to Regularization Anti-Overfitting

Regularization prevents overfitting by penalizing large coefficients — reducing their magnitude so the model doesn't fit noise in training data.

Core Formula Regularized Loss = Loss Function + λ × Penalty where λ = regularization parameter (controls penalty strength)
  • It adds a penalty term to the loss function
  • This discourages the model from assigning large weights to features
  • The more complex the model (larger weights), the bigger the penalty

3.1.1 L1 Regularization (Lasso)

Adds the absolute value of coefficients as a penalty to the loss function.

L1 Penalty Loss + λ × Σ|wᵢ|
  • Some weights become exactly zero, effectively removing irrelevant features
  • Acts as automatic feature selection
  • Useful when only few features are important
  • Good for sparse models
Key Property
L1 produces sparse solutions — coefficients of unimportant features collapse to 0. This makes Lasso a built-in feature selector.

3.1.2 L2 Regularization (Ridge)

Adds the square of coefficients as a penalty to the loss function.

L2 Penalty Loss + λ × Σwᵢ²
  • Shrinks all weights towards zero, but not exactly zero
  • Useful when all features are useful
  • Reduces model variance
  • Good when features are many but all contribute
Key Property
L2 distributes the penalty across all features — none are eliminated, but all are shrunk toward 0.

3.1.3 Elastic Net Regularization

Combines both L1 and L2 penalties. Gets the benefits of both Lasso and Ridge.

Elastic Net Penalty Loss + λ₁ × Σ|wᵢ| + λ₂ × Σwᵢ²
  • Balances feature selection and coefficient shrinkage
  • Removes irrelevant features (L1 effect) AND reduces variance (L2 effect)
  • Works well when features are correlated

3.2 Choosing Lambda (λ)

Lambda controls the strength of regularization. It's a critical hyperparameter to tune.

Small λ → Weak Regularization
Little penalty → Model can still overfit → Complex model possible
Large λ → Strong Regularization
Too much penalty → Weights collapse too much → Model underfits
Optimal λ → Best Balance
Use cross-validation to find the λ value that minimizes validation error
Best Practice
Use cross-validation (e.g., k-fold) to sweep over a range of λ values and pick the one with the lowest validation error.
