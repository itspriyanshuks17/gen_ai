6.1 Why Use Ensemble Methods?

Ensemble learning combines multiple models (called "weak learners") to create a stronger model. Instead of using one predictor, we use many and aggregate their outputs.

  • A single model may be unstable, inaccurate, or biased
  • By combining multiple models we can improve accuracy
  • Reduces both overfitting and underfitting
  • Handles complex problems better

6.2 Types of Ensemble Methods

Bagging
  • Train models in parallel on random subsets
  • Reduces variance (prevents overfitting)
  • Example: Random Forest
Boosting
  • Train models sequentially, focusing on previous mistakes
  • Reduces bias and variance
  • Examples: AdaBoost, GBM, XGBoost

6.2.1 Bagging (Bootstrap Aggregation)

Train multiple models on different random subsets of the data (with replacement) in parallel and aggregate their predictions.

Aggregation Classification → Majority Vote across all models Regression → Average of all model outputs
1
Bootstrap Sampling
Create several bootstrapped datasets (random samples with replacement from original data)
2
Train Independent Models
Train a separate model on each subset independently (in parallel)
3
Combine Results
Majority vote (classification) or average (regression)
Objective
Reduce Variance and prevent overfitting.

6.2.2 Boosting

Train models sequentially, where each model focuses more on the mistakes made by the previous ones.

1
Train First Model
Train the first base learner on the original dataset
2
Identify Errors
Find misclassified/incorrect predictions from the first model
3
Reweight Data
Give more weight to difficult/misclassified points; decrease weight of correctly classified
4
Train Next Model
Train next learner to focus on correcting those weighted mistakes
5
Weighted Combination
Final prediction is a weighted combination of all weak learners' outputs
Objective
Reduce both Bias and Variance, prevents underfitting.

6.3 Random Forest

Random Forest is a Bagging-based ensemble that builds multiple decision trees and combines their results.

What Makes It "Random"?

Random Data Subsets
  • Each tree trained on a random bootstrap sample (with replacement)
Random Feature Subsets
  • At each split, only a random subset of features is considered — not all

Prediction

Classification: Each tree votes → Final = Majority Vote Regression: Each tree gives value → Final = Average
Advantages
  • Reduces overfitting vs. single tree
  • Handles high-dimensional data well
  • Works with missing or unscaled data
  • Less sensitive to noisy data
  • Provides automatic feature importance
Disadvantages
  • Memory-intensive with too many trees
  • Slower than a single tree
  • Can overfit with too many trees (rarely)
