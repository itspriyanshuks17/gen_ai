8.1 Dimensionality Reduction Concepts

Dimensionality Reduction is the process of reducing the number of input features (dimensions) in your dataset. The goal is to retain as much important information as possible while making the data simpler, faster, and easier to analyze or visualize.

Problems with High-Dimensional Data

  • Distance Metrics Collapse: High-dimensional data poses severe challenges for distance-based algorithms like K-Means or DBSCAN. As dimensions increase, all data points become roughly equidistant from each other, rendering distance measures meaningless.
  • The Curse of Dimensionality: As dimensionality increases, the volume of the space expands exponentially. The available data points become extremely sparse, which leads to tiny, fragmented clusters or overfitting.
  • Visualization Limits: It is impossible to visualize data distributions directly when working with more than 3 features or dimensions.
Core Objective
Simplify the data → Make ML training faster → Prevent overfitting → Enable visual exploration in 2D or 3D.

8.2 PCA (Principal Component Analysis) Linear

Principal Component Analysis (PCA) is the most widely used linear dimensionality reduction technique. It assumes that the dataset's features are linearly correlated and projects the data onto a lower-dimensional space.

How PCA Works

PCA transforms the original correlated features into a new set of uncorrelated, orthogonal variables called Principal Components (PCs). These principal components are computed to capture the maximum variance in the data:

1
Standardize the Data
Center the data around the origin and scale it so that every feature has a mean of 0 and variance of 1.
2
Compute Covariance Matrix
Analyze how the features vary together (correlate) by constructing a covariance matrix.
3
Calculate Eigenvectors & Eigenvalues
Solve for the eigenvectors (the directions of the new axes / Principal Components) and eigenvalues (the magnitude of variance captured by each PC).
4
Sort & Project
Sort the Principal Components in descending order of their eigenvalues. Project the original data points onto the top K components.
Properties of Principal Components
  • All Principal Components are **orthogonal (perpendicular)** to each other.
  • The **first component (PC1)** captures the most variation, the **second component (PC2)** captures the next most variation, and so on.

8.3 Comparing PCA, t-SNE, and UMAP

Depending on the goal (preprocessing vs. visualization), you can choose between linear and non-linear reduction techniques:

Feature PCA t-SNE UMAP
Type Linear Non-linear Non-linear
Speed Fast Slow Faster than t-SNE
Structure Preserved Global structure Local structure Local + some global structure
Best For Preprocessing, feature reduction Visualization (2D, 3D) Visualization + downstream tasks
Num. of Dimensions Any Usually 2 or 3 Flexible (2D to many)
Scalability Good for large datasets Poor Better than t-SNE
Use Case Example Speeding up ML models Visualizing word embeddings Visualizing and clustering text
