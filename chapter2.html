2.1 Why Is Feature Engineering Important?

  • An excessive number of features can lead to an overfit model, while too few may result in an underfit model
  • Models like KNN and SVM require predictor variables to share the same unit or scale to prevent bias
  • Some models exhibit high sensitivity to correlations between predictors
  • Models don't understand categorical data — they only understand numbers
  • It helps develop new features that represent something important to the outcome

2.2 Types of Feature Engineering

Feature Transformation
  • Feature Encoding (Label, One-Hot, Frequency, Target)
  • Feature Scaling (Normalization, Standardization)
Feature Extraction
  • Manual extraction (domain knowledge)
  • Binning / Discretization
  • Time-based extraction
Feature Selection
  • Filter methods (Correlation, Chi-Squared)
  • Wrapper methods (RFE, Forward Selection)
  • Embedded methods (Lasso, Tree importance)

2.3.1 Feature Encoding

Convert non-numeric values (like City, Color, Gender) into numbers, because ML algorithms can only understand numbers, not strings or categories.

1. Label Encoding

Assigns each category a unique number.

Example "Red" → 0  |  "Blue" → 1  |  "Green" → 2
✓ Use When
  • Categories are ordinal (have meaningful order)
  • High School → 0, Bachelor → 1, Master → 2, PhD → 3
✗ Avoid When
  • Nominal (unordered) categories
  • Model may think higher number = better/more important

2. One-Hot Encoding

Creates a new binary column for each category (1 = present, 0 = absent). Best for nominal (unordered) categories.

Example City = {Delhi, Mumbai, Kolkata} Creates columns: City_Delhi | City_Mumbai | City_Kolkata
IDCityCity_DelhiCity_MumbaiCity_Kolkata
1Delhi100
2Mumbai010
3Kolkata001
⚠️ Watch Out
Can increase dataset size quickly with too many categories (dimensionality issue / curse of dimensionality).

3. Frequency Encoding

Replace each category with its frequency/count in the dataset.

Delhi = 3 occurrences  |  Mumbai = 1  |  Kolkata = 2
⚠️ Problem
When two categories have the same frequency, they get the same encoded value — which can be ambiguous.

4. Target Encoding

Replace each category with the mean value of the target variable for that category (classification only).

CityMean Purchased (Target)
Delhi(1+0)/2 = 0.5
Mumbai0/1 = 0.0
Kolkata(1+1)/2 = 1.0
⚠️ Risk
Risk of data leakage — apply on training data only with cross-validation. Not suitable for unseen categories in test data.

2.3.2 Feature Scaling

Feature scaling brings all features to a similar scale to improve model performance. Features with larger scales receive more weight, leading to bias.

When to Use Scaling
Use when model relies on distance-based calculations: KNN, Linear Regression, SVM
When NOT to Use Scaling
Tree-based models (Decision Tree, Random Forest, XGBoost) don't need it — they split on thresholds, not absolute values.

Normalization (Min-Max Scaling)

Rescales all values into a fixed range between 0 and 1.

Formula Xᵢ_norm = (Xᵢ − Xₘᵢₙ) / (Xₘₐₓ − Xₘᵢₙ)
Example Age = 25, min = 20, max = 60 → Normalized = (25 - 20) / (60 - 20) = 0.125
⚠️ Weakness
Not good in case of outliers — they compress all other values into a narrow range.

Standardization (StandardScaler)

Rescales data to have Mean = 0 and Standard Deviation = 1.

Formula (Z-score) Xᵢ_standardized = (Xᵢ − μ) / σ where μ = mean, σ = standard deviation
Example Height = 170, mean = 160, std = 10 → Standardized = (170 - 160) / 10 = 1.0
Normalization
  • Range: [0, 1]
  • Sensitive to outliers
  • Good for bounded data
Standardization
  • Mean = 0, SD = 1
  • Better with outliers
  • Best for Logistic Reg., SVM

2.4 Feature Extraction

Feature Extraction is the process of creating new features from raw data that highlight hidden patterns or compress important information. Unlike feature selection (which chooses from existing features), extraction creates new ones.

1. Manual Feature Extraction

Create new features using logic, experience, or real-world domain knowledge.

Raw FeatureExtracted Feature
Date of BirthAge
TimestampDay of Week, Hour of Day
Full AddressCity, State, Zip Code
Review TextLength of Review, Sentiment Score

2. Binning (Discretization)

Group continuous numeric values into categories or buckets. Reduces noise and makes patterns easier to detect.

TypeDescriptionExample
Equal Width BinningDivides values into equal rangesAge: 0–20, 21–40, 41–60
Equal Frequency BinningEqual number of data points in each binTop 25% sales → High, next 25% → Medium
Custom BinningBased on domain knowledgeIncome: Low (<30k), Medium, High

2.5 Feature Selection

Feature Selection is identifying and selecting only the most relevant features from your dataset to train a machine learning model.

Purpose

  • Improve model performance and accuracy
  • Make the model simpler and easier to interpret
  • Speed up training time
  • Reduce overfitting by removing noise features

1. Filter Methods

Independent of any model. Use statistics to select features. Fast and simple.

  • Correlation Matrix (numeric features) → Drop features highly correlated with each other and less correlated with target
  • Chi-Squared Test (categorical + target) → Select features most associated with the output
  • ANOVA F-Test (numeric + categorical target) → Measures variance between groups

2. Wrapper Methods

Use a model to test different combinations of features. Works well with Logistic Regression, Decision Trees.

⚠️ Downside
Computationally expensive for large datasets.
  • Forward Selection → Start with no features, add one at a time based on performance
  • Backward Elimination → Start with all features, remove one at a time
  • Recursive Feature Elimination (RFE) → Repeatedly remove least important features based on a model

3. Embedded Methods

Feature selection happens inside the model training. Model-specific, more efficient than wrapper methods.

  • Lasso Regression (L1) → Shrinks irrelevant feature weights to exactly zero
  • Tree-based feature importance → Decision Trees, Random Forests, and XGBoost rank feature importance internally
