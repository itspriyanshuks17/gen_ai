10.1 Classification Metrics Supervised

Classification metrics measure how correctly a model assigns target classes or labels to input data.

Metric Description & Use Case Mathematical Formula
Accuracy Overall correctness of the model. Best when class distributions are well-balanced.
(TP + TN) / (TP + TN + FP + FN)
Precision Of all predicted positive instances, how many were actually positive. Crucial in cost-minimizing cases like spam detection (reducing false positives).
TP / (TP + FP)
Recall (Sensitivity) Of all actual positive instances, how many were correctly identified. Crucial in high-risk cases like medical diagnostics (reducing false negatives).
TP / (TP + FN)
F1 Score The harmonic mean of precision and recall. Provides a balanced score, especially when dealing with imbalanced target classes.
2 × (Precision × Recall) / (Precision + Recall)

The Confusion Matrix

A structured table mapping actual class labels against predicted ones. Used as the core foundation to compute all evaluation metrics:

Predicted Class
Positive (1) Negative (0)

10.2 Regression Metrics Supervised

Regression metrics quantify the error or deviation between continuous numerical predictions and actual targets.

Metric Description & Interpretation Mathematical Formula
MAE (Mean Absolute Error) The average of the absolute differences between actual values and predictions. Intuitively simple and easy to interpret in same units as the target.
MAE = (1/n) × Σ |y - ŷ|
MSE (Mean Squared Error) The average of the squared errors. By squaring the differences, it **heavily penalizes larger errors**, making it ideal when large mistakes are highly undesirable.
MSE = (1/n) × Σ (y - ŷ)²
RMSE (Root Mean Squared Error) The square root of the MSE. It penalizes larger errors similarly to MSE, but returns the units back to the target's scale for easier interpretation.
RMSE = √(MSE)
R² Score (R-squared) The coefficient of determination. Represents the proportion of variance in the target explained by the input features. Ranges from -∞ to 1 (1 indicates perfect fit).
R² = 1 - [Σ(y - ŷ)² / Σ(y - ȳ)²]

10.3 Clustering Metrics Unsupervised

Clustering metrics evaluate the separation, compactness, and quality of grouped data in unsupervised spaces where ground truth target labels are unavailable.

Silhouette Score

Measures how closely matched a point is to its own cluster compared to neighboring clusters.

s(i) = (b - a) / max(a, b)

Where a represents the mean intra-cluster distance, and b represents the mean distance to the nearest neighboring cluster. Ranges from -1 to +1.

Inertia (Within-Cluster Sum of Squares)

Measures the tightness or compactness of clusters by calculating distance to their respective centroids.

Inertia = Σ (x - cᵢ)²

Calculates the sum of squared Euclidean distances between each point and its assigned cluster centroid $c_i$. Lower inertia indicates tighter clusters (used as K-Means objective function).
