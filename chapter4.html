4.1 Linear Regression Regression

Used to predict a continuous numerical value based on one or more input features using a straight line. Works when the relationship between input and output is roughly linear.

Simple Linear y_pred = θ₀ + θ₁X
Multiple Linear y_pred = θ₀ + θ₁X₁ + θ₂X₂ + ... + θₙXₙ
Residual & Loss Residual = y_actual − y_pred Least Squares = Σ(y_actual − y_pred)² Loss Function: MSE (Mean Squared Error)

Assumptions

  • Linear relationship between inputs and output
  • No multicollinearity (input features shouldn't be too correlated)

Training Steps

1
Initialize
Start with random values for slope and intercept (θ₀, θ₁)
2
Predict
Compute predictions using Y = θ₀ + θ₁X
3
Measure Error
Compare predictions with actual values using MSE
4
Optimize
Use Gradient Descent to update weights and reduce error
5
Repeat
Iterate until error stops improving (convergence)
Advantages
  • Easy to understand and implement
  • Fast to train even on large datasets
  • Doesn't require tuning
Disadvantages
  • Assumes linear relationship (not always true)
  • Very sensitive to outliers
  • Poor with highly correlated features
  • Can underfit complex patterns

4.2 Polynomial Regression Regression

Used to model non-linear relationships. Think of it as linear regression with extra powers of X (X², X³) to better fit curved pattern data.

Key Insight
The underlying model is still linear regression — but the features are transformed to polynomial features (X, X², X³, ...).
Polynomial Y = b₀ + b₁X + b₂X² + b₃X³ + ... + bₙXⁿ where X², X³ = new features (higher-order terms)

Training

  • Add new polynomial features (X², X³, etc.) to your dataset
  • Use regular linear regression to fit those features
  • Find the best curve that minimizes error (like MSE)
Advantages
  • Can model non-linear relationships
  • Uses simple linear model internally
Disadvantages
  • Can create weird curves outside data range
  • Sensitive to outliers
  • High degrees = more overfitting risk

4.3 Logistic Regression Classification

Despite the name, Logistic Regression is a classification algorithm used to classify data into two categories. Instead of predicting a number, it predicts a probability.

Sigmoid Function P = 1 / (1 + e^(−y_pred)) where y_pred = θ₀ + θ₁X
How it Works
The linear score is passed through a sigmoid function → squashes output between 0 and 1 → this probability is converted to class (0 or 1) using a threshold (default 0.5)
Predicted ProbabilityClass (threshold = 0.5)
0.8Class 1 (Yes)
0.3Class 0 (No)

Loss Function

Binary Cross-Entropy (Log Loss) — measures how far off the probability prediction is from the actual class label.

Training

1
Initialize Weights
Start with random weights θ₀, θ₁
2
Compute Score
z = θ₀ + θ₁X for each data point
3
Apply Sigmoid
P = sigmoid(z) → probability between 0 and 1
4
Compute Loss
Cross-entropy loss between predicted probability and actual label
5
Update Weights
Gradient descent to reduce loss
Advantages
  • Works well on linearly separable data
  • Fast to train and predict
  • Easy to understand and implement
Disadvantages
  • Struggles with non-linear relationships
  • Sensitive to outliers
  • Not ideal when features are highly correlated
  • Doesn't handle complex decision boundaries

4.4 Decision Trees Both

A supervised algorithm that mimics human decision-making by breaking a dataset into smaller subsets while building a tree structure. Works for both classification and regression.

Tree Anatomy

Root Node
  • Represents the best feature to split on
  • Top of the tree
Internal Nodes
  • Each represents a feature
  • Contains a decision rule
Branch
  • Represents a decision rule outcome
  • Connects nodes
Leaf Node
  • Classification: gives class label
  • Regression: gives avg numerical value

Training Algorithm

  1. Start with a root node
  2. Find the feature that best splits data into its pre-labeled classes
  3. Each split partitions the input data → passes along branches to new nodes
  4. Repeat for each new node (each feature used only once) until stopping criterion

Tree Pruning

A deep tree may overfit. Pruning removes less informative branches to improve generalizability.

  • Maximum depth is reached
  • Minimum number of data points in a node exceeded
  • Minimum samples in a leaf exceeded
  • Maximum number of leaf nodes reached

Choosing the Best Feature — Splitting Criteria

The Goal
Find the feature that splits data to produce the purest possible child nodes.
For Classification
  • Entropy — measures information disorder
  • Information Gain — how much entropy is reduced by a split
  • Higher IG = better feature for splitting
For Regression
  • MSE — Mean Squared Error
  • MAE — Mean Absolute Error
  • Minimizes prediction error in each leaf
Entropy Entropy = −Σ pᵢ × log₂(pᵢ) If entropy = 0 → pure node (one class only) Higher entropy = more mixed classes

4.5 Support Vector Machines Both

SVM (Support Vector Machine) is used for both classification (SVC) and regression (SVR).

Core Idea
SVM tries to find a hyperplane that divides data into two classes with the widest possible margin between the closest points (support vectors) of each class.

Key Concepts

Hyperplane
  • The decision boundary separating classes
  • In 2D: a line; in 3D: a plane
Support Vectors
  • Data points closest to the hyperplane
  • These define the margin boundaries
Margin
  • Distance between hyperplane and support vectors
  • Larger margin = better generalization

Soft Margins (C Parameter)

Real data is noisy and overlapping. Soft margins allow some misclassifications to achieve a better overall margin.

C ValueMarginEffect
Low CSoft (wide)More misclassifications, high bias, underfitting risk
High CHard (narrow)Fewer errors, but risk of overfitting

Kernels — Handling Non-Linear Data

Real-world data is rarely linearly separable. SVM uses kernel tricks to transform data into higher dimensions where a hyperplane can separate them.

KernelUse Case
LinearWhen data is linearly separable
PolynomialWhen data has polynomial relations
RBF (Radial Basis Functions)Most commonly used for complex, non-linear data
SigmoidLess common; similar to neural network activation

SVR — Epsilon Parameter

SVR Epsilon Tube Smaller ε → Tighter tube → Overfitting Larger ε → Allow error → Smoother model (less noise-sensitive)

Points inside the epsilon tube: No penalty. Points outside: Penalized (adds to loss).

Advantages
  • High accuracy in high-dimensional spaces
  • Handles linear and non-linear data
Disadvantages
  • Poor performance on large datasets
  • Requires careful hyperparameter tuning
  • Harder to interpret than decision trees
  • Struggles with noisy overlapping classes

4.6 K Nearest Neighbors (KNN) Both

KNN predicts a value or class based on how its nearest neighbors are labeled. Also called a lazy learner because it does no computation during training.

Why "Lazy Learner"?
  • No computation during training (just memorizes data)
  • All computation happens at prediction time
  • Computes distances to all training points for each new input

Working

  1. Pick a value for K (number of neighbors)
  2. For each query point, measure distance to all training samples
  3. Select K nearest neighbors (top-K smallest distances)
  4. For Classification: pick majority class among neighbors
  5. For Regression: take average/median of neighbors' target values

Handling Imbalanced Classes

In skewed/imbalanced datasets, new predictions will tend to belong to the majority class.

Solution 1: Weight Classification
  • Assign weights to neighbors based on distance
  • Closer neighbors get more influence
Solution 2: Resampling
  • Oversampling minority class (SMOTE)
  • Undersampling majority class
⚠️ Curse of Dimensionality
As number of features increases, distances become less meaningful — all points appear equidistant. KNN suffers badly with many features.
Advantages
  • No training time
  • Works well with small datasets
  • Naturally adapts to new data
Disadvantages
  • Requires storing entire dataset (memory-heavy)
  • Slow predictions on large datasets
  • Sensitive to irrelevant/noisy features
  • Requires feature scaling
  • Suffers from curse of dimensionality
