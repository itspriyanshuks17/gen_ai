9.1 Model Validation Concepts

Hyperparameters are the settings of the model that you choose and configure manually before training begins (such as the number of trees in a random forest, learning rate, regularization coefficient $\lambda$, or K in KNN).

Model Validation is the process of testing how well your model performs on unseen data. Optimizing hyperparameters without compromising the validation process prevents overfitting when selecting the best configuration.

Validation Set
A subset of the training set used during model optimization to evaluate different configurations (hyperparameters) without touching or leaking the final test data.

9.2 Data Splitting Strategy

To properly train and evaluate models, datasets are divided into three mutually exclusive subsets:

🏋️ Training Set

Used by the algorithm to learn patterns, optimize weights, and fit model parameters.

🔬 Validation Set

Used during model tuning to evaluate different hyperparameter combinations and select the best setup.

🎯 Test Set

Held back completely until the final step. Used to provide an unbiased estimate of real-world generalization performance.

9.3 Cross-Validation Methods

Cross-Validation is a robust and effective method to validate your model by utilizing all available data for both training and validation without leaking information.

It splits the dataset into multiple folds, trains the model, and validates it multiple times across different configurations.

Types of Cross-Validation

1
K-Fold Cross-Validation
  • Split the dataset into K equal-sized parts (folds).
  • Use K-1 folds to train the model, and the remaining 1 fold for validation.
  • Repeat this process K times, rotationally changing the validation fold.
  • Average the performance metrics across all K runs to obtain a stable score.
2
Stratified K-Fold Cross-Validation
Like K-Fold, but ensures that each fold maintains the same percentage of samples for each target class as the complete dataset. Essential for imbalanced classification tasks to prevent folds from missing class representations.
3
Time Series Split
Used for time-series and sequential data where data ordering is critical. It ensures that the validation set always chronologically follows the training set, preventing the model from "peeking" into the future.

9.4 Methods of Hyperparameter Tuning

Two primary strategies are used to search the hyperparameter configuration space:

Grid Search (Exhaustive)

Attempts **every single possible combination** of hyperparameters within a predefined search grid.

  • Guarantees finding the absolute best point in the defined grid.
  • ⚠️ Highly computationally expensive and slow. Complexity scales exponentially with the number of hyperparameters.
Random Search (Stochastic)

Evaluates a **randomly sampled selection of configurations** from the hyperparameter space for a fixed number of iterations.

  • Drastically faster and more efficient than Grid Search.
  • Highly effective because most model performances are dominated by only a few key hyperparameters.
