Architectural Overview

Semantic Search & RAG Pipelines

Modern information retrieval uses **Asymmetric Dual Encoders** to map queries and documents into a shared latent space. In a production **Retrieval-Augmented Generation (RAG)** pipeline, this happens in two distinct phases:

1. Background Indexing: Large document collections are parsed, divided into chunks, converted into dense document vectors using the RETRIEVAL_DOCUMENT model tower, and indexed inside a low-latency Vector Database (like Faiss, HNSW, or ScaNN).
2. Real-Time Querying: When a user enters a query, it is compressed into a query vector using the RETRIEVAL_QUERY model tower. The Vector Database retrieves the nearest neighbors in milliseconds. These chunks are stuffed into an LLM's context window to generate a grounded, factual answer.
