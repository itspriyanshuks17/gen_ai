What are Embeddings?

Low-dimensional numerical vectors that represent real-world data (text, images, audio). Geometric distance in vector space mirrors semantic similarity between objects.

Why Vector Search?

Traditional keyword search can't capture semantic meaning. Vector search enables finding conceptually similar items across billions of entries in milliseconds.

Production Pipeline

Precompute embeddings → Store in vector DB → Embed queries → ANN search → LLM generation. Each step has specialized tools and trade-offs to understand.

⚡ Key Formulas at a Glance
Precision@k = relevant / k

Fraction of retrieved docs that are relevant

Recall@k = retrieved_rel / total_rel

Fraction of relevant docs that were retrieved

DCG = Σ rel_i / log₂(i+1)

Discounted Cumulative Gain — penalizes low rank

nDCG = DCG / IDCG

Normalized DCG, range 0.0–1.0

L2 = ||a - b||₂

Euclidean distance (good for low-dim)

cos(θ) = a·b / (|a||b|)

Cosine similarity (angle between vectors)
